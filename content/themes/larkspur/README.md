# Larkspur

An editorial Vuuut storefront for objects, textiles, and independent design.
The homepage pairs a replaceable cover photograph with featured products
a collection feature, an arrivals shelf, and a current offers panel. The catalogue supports search and sorting. Product
pages use Vuuut's variant, inventory, cart, and checkout flows.

## Set up the storefront

1. Activate **Larkspur** in **Settings → Design** and enable **Tools → E-commerce**.
2. Publish products and collections in the store. Mark products as featured to
   curate **The shop edit**. The homepage hides the edit when none are featured. It lists newer products
   that are outside the edit and excludes current sale items from the arrivals shelf.
   When there are no populated collections, the collection area can showcase
   a separate product outside the arrivals shelf.
3. Set the homepage heading, introduction, and image in **Design**. The
   heading and introduction have theme defaults.

## Sample catalogue

On a test store, import [larkspur-products.csv](demo/larkspur-products.csv)
through **Tools → E-commerce → Products → Import**. The CSV uses the theme's
bundled sample photos. Mark Iris Vase, Loop Mug, and Ripple Bowl as featured
to preview the product edit. Create collections for Ceramics, Tableware, and
Textiles, and assign the corresponding products to preview the collection
grid. The catalogue contains fictional products and sample prices.
