# Stackline

Stackline is a Vuuut theme for coding schools. It includes a responsive homepage, a searchable course catalogue, course details and syllabus, a lesson player, and the My learning dashboard.

Enable **LMS & Online Courses** in Vuuut and select **Stackline** under **Themes** in the Vuuut admin. Publish your courses and assign topics in the LMS. Mark a course as featured to put it in the homepage spotlight. Quick courses lists non-featured courses with a recorded duration of up to 60 minutes. The six language shortcuts open catalogue searches. Upload course covers in the LMS to replace the built-in code artwork.

Theme settings let you change the homepage copy, hide the topic or journal section, and set the default light or dark appearance. If you move the LMS off the default `/courses/` route, set **Catalog address** to its path, including the trailing slash.

Plus Jakarta Sans is self-hosted under the SIL Open Font License 1.1.
